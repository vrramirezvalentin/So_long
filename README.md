# So_long
So_long is a C project that opens a window to display a 2D game where the player navigates through a maze. It uses graphics libraries to manage display, movement, and interactions in a simple yet interactive environment.

![So_long Screenshot](https://github.com/vrramirezvalentin/So_long/raw/main/so_long_screenshot.png)


## How to Play

In So_long, your goal is to navigate the maze, collect all the necessary items, and find your way to the exit. But be careful each move counts, so plan your path wisely.

### Keyboard Controls

| Key         | Action          |
|-------------|-----------------|
| **W** / ↑   | Move Up         |
| **S** / ↓   | Move Down       |
| **A** / ←   | Move Left       |
| **D** / →   | Move Right      |
| **ESC**     | Close Game      |
